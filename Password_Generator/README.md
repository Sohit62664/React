# 🔐 Password Generator

A simple and responsive **Password Generator** built using **React.js** and **Tailwind CSS**. It allows users to generate random passwords with customizable length, numbers, and special characters.

## 🚀 Live Demo

[View Password Generator](https://react-jet-seven-83.vercel.app/?utm_source=chatgpt.com)

## ✨ Features

* 🔑 Generate random passwords instantly
* 📏 Select password length from **6 to 100 characters**
* 🔢 Option to include numbers
* 🔣 Option to include special characters
* 📋 Copy generated password to clipboard
* ⚡ Password updates automatically when settings change
* 📱 Responsive and clean user interface
* 🌙 Modern dark-themed design

## 🛠️ Tech Stack

* **React.js**
* **JavaScript**
* **Tailwind CSS**
* **Vite**
* **Vercel** for deployment

## 📚 React Concepts Used

This project helped me practice several important React concepts:

* `useState` — managing password settings and generated password
* `useCallback` — memoizing password generation and copy functions
* `useEffect` — regenerating the password when settings change
* `useRef` — accessing and selecting the password input
* Event handling
* Controlled inputs
* Component rendering

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Sohit62664/React.git
```

Navigate to the project:

```bash
cd React/Password_Generator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🏗️ Production Build

To create a production build:

```bash
npm run build
```
